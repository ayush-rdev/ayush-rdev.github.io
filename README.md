## 📖 Overview

This repository hosts the static source and deployment artifacts for **[ayush-rdev.github.io](https://ayush-rdev.github.io/)**, an independent digital garden, technical blog, and portfolio dedicated to:
* **Operating Systems & Desktops**: Linux kernel, Wayland protocols, and Hyprland rices.
* **Local-First Software**: Data sovereignty, file-over-app computing, and offline-first architectures.
* **Security & Infrastructure**: Containerization, offensive security research, and network privacy.
* **Thoughts & Philosophy**: Unfiltered personal essays and long-term reading notes.

## ⚡ Quickstart

To run and preview the site locally on your workstation:

```bash
# Clone the repository
git clone https://github.com/ayush-rdev/ayush-rdev.github.io.git
cd ayush-rdev.github.io

# Serve with any static web server (e.g. Python, Node, Caddy)
python3 -m http.server 8000
```

Open `http://localhost:8000` in your web browser.

```

├── index.html            # Homepage: Recent thoughts, featured work & bio

├── posts/                # Technical essays, guides, and long-form articles
```

---

## 🎨 Design Philosophy

* **Typography First**: Clean, comfortable proportions calibrated for long-form reading without cognitive fatigue.
* **Zero Bloat**: No heavy frameworks, zero third-party tracking scripts, zero surveillance telemetry.
* **Instant TTFB**: Static HTML/CSS delivering instantaneous page loads across both mobile and desktop.
